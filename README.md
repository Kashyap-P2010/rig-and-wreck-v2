# Rig & Wreck

Physics sandbox contraption builder for Roblox.
Spawn props, wire motors, attach thrusters, link welds and ropes, and wreck contraptions with TNT.
Usem magnets as well, Save and load your creations easily, access for mobile as well!

Built with Rojo. Sync into Roblox Studio with:
```bash
rojo serve
```
